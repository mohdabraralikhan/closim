# G12 — Size Grading & Multi-Size Garments

The commercial goal is:

```text id="g12target"
ONE MASTER PATTERN
       ↓
SIZE SET
XS ─ S ─ M ─ L ─ XL ─ XXL
       ↓
Grading Rules
       ↓
Validated Multi-Size Pattern
       ↓
Nested / Exportable Files
```

The critical architectural rule:

> **The base/master pattern remains the source of truth. Graded sizes are derived representations.**

Do not permanently distort the master pattern to create another size.

# G12A — Size Grading Data Model

Repository:
C:\Users\Abrar\Desktop\closim

G11 is complete.

Build the foundational size-grading model.

## Objective

Represent a master garment pattern and its derived size set without destructive geometry changes.

Architecture:

Master Pattern
    ↓
Size Definition
    ↓
Grade Rule
    ↓
Derived Size Geometry

## Required entities

Implement stable-ID structures for:

- Size
- SizeSet
- MasterPattern
- GradingPoint
- GradeRule
- GradeRuleTable
- GradedPattern

Each must have deterministic serialization.

## Size definition

Support:

- size ID
- display name
- numeric/textual label
- ordering
- body-measurement references
- active/inactive state

Do not hard-code a particular market's size naming convention.

## Grading points

A grading point must reference an existing pattern entity using stable IDs.

Support:

- point
- edge-relative point
- corner
- seam-related point where appropriate

Do not use array positions as persistent references.

## Grade rules

A rule must support directional changes in pattern coordinates.

At minimum represent:

- delta X
- delta Y

per target size or size transition.

Support both:

```text
Master → Target Size
```

and

```text
Size N → Size N+1
```

where useful.

## Derived geometry

Graded geometry must be generated from:

```text
master geometry + size definition + grading rules
```

The master geometry must remain untouched.

## Invalidation

Changing:

- master geometry
- grading point
- size table
- grade rule

must invalidate dependent graded geometry deterministically.

## Tests

Test:

- one size
- multiple sizes
- missing rule
- duplicate rule
- invalid grading point
- deleted source entity
- size insertion
- size deletion
- save/load
- deterministic regeneration

Definition of done:

A master garment can deterministically generate multiple derived sizes through persistent grading data.

# G12B — Grade Rule Engine

# G12B — Grade Rule Engine

Repository:
C:\Users\Abrar\Desktop\closim

G11 is complete.

Implement the grading-rule evaluation engine.

## Objective

Convert grading definitions into deterministic target-size geometry.

## Core calculation

For each grading point:

Target position =
Master/reference position
+ accumulated grade delta

Support:

- X/Y deltas
- per-size deltas
- transition deltas
- independent panel rules
- independent point rules

## Rule organization

Support:

- size-to-size rule chains
- master-relative rules
- panel-specific overrides
- point-specific overrides

Define precedence explicitly.

Do not allow ambiguous rule conflicts.

## Geometry propagation

When a grading point moves, dependent geometry must update according to its semantic relationship.

Avoid blindly translating unrelated geometry.

Preserve:

- boundary connectivity
- seam references
- production markings where their anchors remain valid
- construction relationships

## Special cases

Handle:

- curved boundaries
- intermediate points
- mirrored panels
- shared seam points
- construction geometry
- production markings
- fold lines
- grainlines

Anything that cannot safely grade automatically must produce an explicit diagnostic.

## Validation

Detect:

- missing rules
- conflicting rules
- invalid point references
- inconsistent size direction
- impossible derived geometry
- self-intersection after grading
- seam mismatch after grading

## Determinism

Identical master pattern + identical rules must produce identical target geometry.

## Tests

Create tests for:

- 2 sizes
- 5+ sizes
- linear grading
- asymmetric grading
- mirrored panels
- seam-linked points
- curved boundaries
- invalid rules
- self-intersection
- regeneration after master edit

Definition of done:

The engine can generate deterministic graded geometry while preserving valid garment topology.
